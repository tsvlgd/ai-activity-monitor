## Codex search notes

No official Codex specific mark was found in a downloadable form:

* github.com/openai/codex: the only brand image is `.github/codex-cli-splash.png` (1898 x 1190), a terminal screenshot with no logo in it, so nothing could be cropped from it. Other repo images are skill sample icons.
* developers.openai.com/codex (and /codex/app, /codex/cli, /codex/ide): only UI icons and the OpenAI Developers wordmark.
* openai.com/codex: returned HTTP 403 to scripted fetches.
* The OpenAI published VS Code extension `openai.chatgpt` (listed as Codex) uses the white blossom on a black square, which matches codex.svg.

So codex.svg is the official OpenAI blossom. The LobeHub files show the real Codex app mark but are not from OpenAI; use them only if the team accepts an unofficial source.
